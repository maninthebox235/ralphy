# 🎯 Simplified Version - ADHD-Friendly

## What Changed?

I created `dax-simple.html` - a dramatically simplified version perfect for ADHD users.

### ❌ **REMOVED** (Reduced Overwhelm):
- ✂️ Sidebar navigation (one less thing to process)
- ✂️ Dark mode toggle (fewer options = less decision fatigue)
- ✂️ Expand/collapse all buttons (unnecessary controls)
- ✂️ Print button (not needed for phone use)
- ✂️ Favorites system (adds complexity)
- ✂️ Install banner (shows up later, less nagging)
- ✂️ Extra sections (billing, troubleshooting, success metrics)
- ✂️ Long sample note (too much text)
- ✂️ Pro tips section (moved to simple bullets)

### ✅ **KEPT** (Essential Only):
- ✨ **Search** - One input at top, always visible
- ✨ **3 bottom nav buttons** - Quick, Breast, Ovarian (most common)
- ✨ **Copy buttons** - One tap to copy any template
- ✨ **Collapsible cards** - Tap header to expand/collapse
- ✨ **Clean design** - Less visual noise

---

## 🎨 Design Changes for ADHD:

### 1. **Clearer Visual Hierarchy**
- Bigger, clearer section titles
- More whitespace
- Simpler color scheme (just teal, no gradients everywhere)
- Fewer competing elements

### 2. **Reduced Cognitive Load**
- Only 6 main cards (vs 12 sections)
- Most cards start collapsed
- Bottom nav shows only 3 options (not 4)
- No floating buttons competing for attention

### 3. **Faster Access**
- Top cards are most-used (Quick Templates, Breast, Ovarian)
- Search is always visible
- One-tap copy on everything
- Less scrolling needed

### 4. **Less Decision Fatigue**
- No dark mode toggle to think about
- No favorites to manage
- No expand/collapse all decisions
- Just: search, tap, copy, done
